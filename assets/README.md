# Demonstration asset provenance

The sample products, specifications, brand and contact details are fictional. The cabinet and side table images are the original schematic illustrations supplied in the v0.1.0 MIT project. The bench, shelf and geometric logo are original drawings generated by `examples/make_examples.py`. These project assets and the generated example catalogs are available under the repository's MIT license. The sample email uses the reserved `example.invalid` domain.

The PDF renderer uses Bitstream Vera fonts furnished with ReportLab. The font license applies to that typeface and its embedded subsets. [Bitstream Vera license](bitstream-vera-license.txt)
