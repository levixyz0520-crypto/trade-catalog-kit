# Security policy

The current minor release receives security fixes. Report a vulnerability privately using [GitHub private vulnerability reporting](https://github.com/levixyz0520-crypto/trade-catalog-kit/security/advisories/new). Include the affected version, impact and a minimal description using synthetic data. Remove secrets, private catalogs and real contact details before attaching files.

The normal workflow reads local spreadsheets and images. CLI image filenames are limited to the selected directory. The Streamlit workflow keeps uploaded inputs and output in the active session, and the optional AI mode downloads a model on first use. For confidential material, run the app on a trusted workstation or private deployment.
